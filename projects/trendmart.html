Trend Mart — Full-Stack E-Commerce Platform

Building a production-quality e-commerce system requires solving authentication, inventory management, payment processing, and admin operations simultaneously. Trend Mart tackles all four, delivering a complete MERN-stack storefront with role-based access control, real-time cart management, and a dual-deployment architecture across Vercel and Render.

View on GitHub Explore Project

Project Overview

E-commerce platforms demand careful orchestration between user-facing storefront interactions and backend inventory, order, and payment pipelines. Trend Mart approaches this as an engineering challenge rather than a template exercise — every component from JWT session management to order receipt generation was built from scratch.

The platform supports the complete purchase lifecycle: product browsing with filters and search, dynamic cart with persistent state, integrated UPI and Visa payment flows, and automated PDF receipt generation via PDFKit. An admin dashboard provides real-time control over product catalog, user management, and order processing with secure role-based access.

The frontend leverages React with Redux for predictable state management, while the backend implements a modular Express API architecture designed for horizontal scalability. Cloud deployment separates concerns — frontend on Vercel for edge performance, backend on Render for API reliability.

Key Features

Engineered to simulate a real-world e-commerce operation with production-grade authentication, inventory, and payment systems.

JWT Authentication

Secure session management with bcrypt password hashing, HTTP-only cookies, and separate privilege levels for customers and administrators.

Product Management

Full CRUD operations for products with category management, image handling, pricing controls, and CSV-based bulk data seeding for scalability testing.

Cart and Wishlist

Dynamic cart with real-time quantity updates, automatic total calculations, and persistent localStorage state. Wishlist functionality enhances browsing experience.

System Architecture

Loading diagram...
  • Frontend: React with Vite for fast builds, Redux for state management, Bootstrap 5 for responsive UI, and Axios for API communication. Dark mode support included.
  • Backend: Express.js with modular route architecture, JWT middleware for authentication, and controller-based business logic separation.
  • Database: MongoDB Atlas provides scalable cloud storage with Mongoose ORM for schema validation and relationship management.
  • Deployment: Dual-service architecture — frontend on Vercel for CDN-backed edge delivery, backend on Render for reliable API hosting.

Challenges & Learnings

Challenges Faced
  • Designing a cart system that maintains consistency between localStorage persistence and server-side order state
  • Implementing role-based access control that cleanly separates admin and customer authorization without code duplication
  • Managing deployment configuration across two separate hosting platforms while maintaining API reliability
Key Learnings
  • Redux middleware significantly simplifies complex async state transitions in cart and order flows
  • JWT-based middleware is the backbone of secure full-stack applications — understanding token lifecycle is critical
  • Dual-deployment architectures require careful CORS configuration and environment-aware API routing

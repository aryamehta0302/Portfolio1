AIML Department Chatbot — Retrieval-Augmented AI Assistant

Academic departments field thousands of repetitive queries every semester — admissions, schedules, faculty details, event information. This chatbot eliminates that bottleneck by combining TF-IDF document retrieval with Google Gemini's generative capabilities to deliver accurate, contextual answers in multiple languages with voice support.

View on GitHub Explore Project

Project Overview

Standard FAQ pages and static documents fail to serve students effectively — they require manual searching through outdated content and offer no interactive guidance. This project reimagines departmental information access as an intelligent conversation.

The system indexes departmental documents using TF-IDF vectorization and retrieves the most relevant context via cosine similarity scoring. This retrieved context, combined with the user's query, is sent to Google Gemini Flash, which generates structured, professionally formatted responses — including tables, bullet points, and step-by-step guides where appropriate.

Multilingual support across English, Hindi, Gujarati, Tamil, and Telugu, combined with speech-to-text input and text-to-speech output, ensures accessibility for the diverse student population the system serves.

Key Features

Designed to automate student-department communication and reduce faculty workload through AI-driven Q&A.

Retrieval-Augmented Generation

TF-IDF indexing with cosine similarity retrieves the most relevant departmental documents, grounding Gemini's responses in verified institutional data.

Google Gemini Integration

Gemini Flash generates clean, structured responses — formatting answers with tables, lists, and step-by-step instructions based on query complexity.

Multilingual Voice Support

Supports five languages with bidirectional translation, speech-to-text input, and text-to-speech output for comprehensive accessibility.

System Architecture

Loading diagram...
  • Query Processing: User input arrives via text or speech-to-text, is normalized, and routed to the retrieval pipeline.
  • Document Retrieval: TF-IDF vectorized departmental documents are scored against the query using cosine similarity, extracting the top-K most relevant passages.
  • Response Generation: Retrieved context is injected into the Gemini Flash prompt, producing grounded, structured answers that stay factual to source material.
  • Output Delivery: Responses are optionally translated and converted to speech, supporting multilingual voice interaction end-to-end.

Challenges & Learnings

Challenges Faced
  • Curating and structuring departmental data from disparate, inconsistently formatted sources into a coherent document corpus
  • Tuning retrieval precision to return contextually relevant passages without information overload in the prompt
  • Ensuring translation accuracy across five languages for domain-specific academic terminology
Key Learnings
  • Retrieval-augmented generation dramatically reduces hallucination compared to purely generative approaches on domain-specific queries
  • TF-IDF remains a highly effective retrieval method for structured document collections where semantic search adds unnecessary complexity
  • Multimodal interaction (text + voice) significantly increases adoption and accessibility across diverse user demographics

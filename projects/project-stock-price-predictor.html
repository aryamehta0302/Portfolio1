Stock Price Predictor — AI-Driven Financial Forecasting

Financial markets generate vast amounts of time-series data, yet extracting actionable predictions remains a significant challenge. This system leverages XGBoost regression on real-time Yahoo Finance data, combining engineered technical indicators to predict next-day closing prices for any global stock ticker.

View on GitHub Explore Project

Project Overview

Traditional stock analysis relies heavily on manual chart interpretation and lagging indicators. This project automates the feature engineering and prediction pipeline, transforming raw OHLCV data into a structured forecasting workflow that quantifies market momentum, volatility, and trend direction.

The system fetches six months of historical data via the Yahoo Finance API, engineers features including Simple Moving Averages, Exponential Moving Averages, and momentum indicators, then trains an XGBoost model that captures non-linear market dynamics. Interactive Matplotlib visualizations compare forecast trajectories against actual price movements, providing decision-support context for traders and analysts.

Prediction Pipeline

Loading diagram...
  • Data Acquisition: Yahoo Finance API fetches real-time OHLCV data for any global ticker symbol, providing the raw dataset for feature extraction.
  • Feature Engineering: Technical indicators including SMA, EMA, volatility bands, and momentum oscillators are computed to capture short-term and long-term market signals.
  • Model Training: XGBoost regression with hyperparameter tuning optimizes prediction accuracy on the engineered feature set.
  • Evaluation: MAE, RMSE, and R-squared metrics quantify model performance, with visual comparisons validating prediction quality.

Challenges & Learnings

Challenges Faced
  • High market volatility introduces sudden price spikes that degrade prediction consistency
  • Selecting appropriate error metrics for financial forecasting where magnitude matters more than direction
  • Handling missing data points during holidays, weekends, and market closures without introducing bias
Key Learnings
  • Engineered technical indicators contribute more predictive signal than raw price features alone
  • Time-series cross-validation is essential to prevent overfitting on sequential financial data
  • Visualization transforms abstract ML predictions into actionable decision-support insights

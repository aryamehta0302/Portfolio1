BlogSpot — Content Publishing Platform

Content management systems require careful orchestration between publishing workflows, access control, and user engagement features. BlogSpot addresses this complexity head-on, delivering a full-featured MERN-based platform with rich text editing, role-based authorization, category management, and a moderation dashboard — built entirely from scratch without CMS templates.

View on GitHub Explore Project

Project Overview

Most blogging platforms abstract away the engineering complexity behind their interfaces. BlogSpot deliberately exposes and addresses each layer — authentication, content management, user interaction, and administration — to demonstrate full-stack architectural thinking applied to a real publishing workflow.

The platform implements JWT-based session management with HTTP-only cookies, ensuring secure persistent sessions without exposing tokens to client-side JavaScript. Role-based middleware separates admin and user capabilities at the API level, preventing unauthorized access to content moderation and platform configuration endpoints.

Authors create content through a rich text editor with image embedding and formatting controls, while readers interact through comments and category-based content discovery. The admin dashboard provides centralized control over all published content, user accounts, and category taxonomy.

Key Features

Rich Text Editor

Component-based editor supporting formatted text, inline images, and structured content — producing publication-ready blog posts.

JWT Authentication

Secure session management with HTTP-only cookie storage, bcrypt password hashing, and automatic token refresh for persistent login.

Admin Dashboard

Centralized content moderation with post approval, category management, user oversight, and platform-wide configuration controls.

Category-Based Discovery

Hierarchical category taxonomy enables content organization and filtered browsing, improving reader navigation and engagement.

Comments System

Authenticated commenting on published posts with real-time rendering , enabling reader interaction and discussion.

Profile Management

User dashboards display authored posts, account settings, and activity history — giving authors control over their publishing presence.

System Architecture

Loading diagram...
  • Authentication: JWT tokens stored in HTTP-only cookies provide secure, persistent sessions. Bcrypt handles password hashing with configurable salt rounds.
  • API Layer: Express.js exposes RESTful endpoints with modular routing — separate controllers for blog operations, user management, and admin functions.
  • Access Control: Role-based middleware intercepts requests before controller execution, enforcing admin-only restrictions on sensitive operations.
  • Data Layer: MongoDB with Mongoose ORM manages blog posts, user profiles, comments, and category relationships with schema validation.

Challenges & Learnings

Challenges Faced
  • Implementing secure route protection that cleanly separates role-based access without duplicating authorization logic
  • Maintaining consistent responsive layouts between the content editor, listing pages, and admin views across device sizes
  • Designing a scalable database schema that efficiently handles nested relationships between posts, comments, categories, and users
Key Learnings
  • Modular API architecture with reusable middleware significantly reduces code duplication and simplifies maintenance
  • HTTP-only cookie-based JWT storage provides materially better security than localStorage approaches
  • Strong visual hierarchy and consistent typography are as important as technical functionality for user engagement
